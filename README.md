# Seed Oasis — QR Profile Landing Page

A premium, mobile-first landing page that users reach by scanning a QR code. Displays profile information, social media links, and contact actions for **Seed Oasis**.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| React 19 | UI Framework |
| Vite 8 | Build Tool |
| TypeScript 6 | Type Safety |
| Tailwind CSS 4 | Utility-first Styling |
| Framer Motion 12 | Animations |
| React Icons 5 | Icon Library |
| React Helmet Async | SEO Meta Tags |

## 📁 Project Structure

```
src/
├── components/       # UI components (layout, profile, links, actions, ui, seo)
├── hooks/            # Custom React hooks (useTheme, useClipboard, useShare)
├── data/             # Static configuration (profile, socialLinks, theme)
├── utils/            # Utilities (cn, vcard)
├── assets/           # Static images
├── App.tsx           # Root component
├── main.tsx          # Entry point
└── index.css         # Tailwind + design system
```
